### idsHOy2varce

> [!summary] Cumulative Summary
> **Open‑source** large language models (LLMs) allows one to contribute and / or modify the original code; in contrast, **closed-source** LLMs are proprietary, under strict ownership, to the company, and users are limited to a Software as a Service (SaaS) model.

<!-- blockquote separator -->

> [!quote]
> An open‑source LLM is a language model whose model weights and code are publicly available. This means anyone can download them, study how they work, and even change them to better fit their needs.
> .
> .
> .
> This is very different from proprietary models like ChatGPT or Claude. With those, the company controls the technology. You don't get access to the model weights. Instead, you interact with the model through an API or a web interface, and you have to follow strict usage rules. In other words, you use the model as a service, not as something you can fully own or adapt.

<!-- blockquote separator -->

> [!note] Marginalia / Reflection
>
> - Open‑source large language model (LLM)
>   - Both code and weights of the model are open for contribution and review
> - Closed-source large language model (LLM)
>   - Companies control the model
>   - Can not modify or customize the model's wights
>   - Only available via an API or a web interface

### idtWc82pOhMi

> [!quote]
> Open‑source models stand out in four main ways. Anyone can download and run the models. You don't always need to rely on an external provider to use them. In this sense, they are really accessible. Another aspect is transparency. Because the weights and code are available, developers and researchers can openly examine what's happening under the hood. You can also fine‑tune the model, add new data, or adapt it for specific languages, domains, or industries. This makes the model highly customizable. Open‑source licenses often give you more rights to modify, redistribute, or build on top of the work compared to closed commercial licenses that are tightly controlled. For developers, the benefits are huge. You get the freedom to experiment without heavy restrictions, the ability to avoid vendor lock‑in, and the power to adapt the model to your exact needs.

<!-- blockquote separator -->

> [!note] Marginalia / Reflection
> Benefits of open‑source large language models (LLMs):
>
> - **Accessibility:** it's open‑source (duh)
> - **Transparency:** the algorithm and code is not a black-box
> - **Customizability:** one can modify and distribute their own version of the source code
> - **Licensing freedom:** no restrictions by way of pricing or any anti-consumer patterns and no vender lock-in
