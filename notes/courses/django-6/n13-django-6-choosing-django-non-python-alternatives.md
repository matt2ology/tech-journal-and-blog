## Non-Python Alternatives

### [Laravel](https://laravel.com/)

Django has a "better" featured admin interface - nevertheless:

- A popular framework written in [PHP](https://www.php.net/) - built using the model‑view‑controller architecture
- Feature complete (batteries included)
  - Data model layer & migration support
  - Templating system
  - Authentication
  - Form validation
  - etc.
- [Great documentation](https://laravel.com/framework/docs/installation)

### [.Net Core](https://learn.microsoft.com/en-us/aspnet/core/overview?view=aspnetcore-10.0)

- A popular C# framework
- Similar feature sets, but lacks the robust admin interface of Django
- C# is a statically typed compiled language, which means that .NET Core will typically be able to achieve better performance than Django.
