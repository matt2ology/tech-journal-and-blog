## Folder Structure of a Django Project

The directory structure of projects

A the top-level we have the, entire, project folder.

Within the project folder, a folder that shares the same name, is the "main project folder".

The "all encompassing project" folder contains:

- **`templates` folder:** HTML files
- **`media` folder:** contains photos
- **`venv` folder:** the Python virtual environment

The "**main** project **folder**" contains the following Python files:

- **`__init__.py`:**
- **`asgi.py`:** files that hold settings for deploying the application to production
- **`settings.py`:** a file where we can configure any setting for our project
  - Connect to a database
  - Configure 3rd party packages
- **`urls.py`:** holds URL mappings
- **`wsgi.py`:** files that hold settings for deploying the application to production

All other folders not generated by default from Django are referred to as "Django apps"

- A project can be broken into subprojects called "apps" (e.g. a "trips" app holds all the code related to trips)
- Apps adds structure to projects
- Each app contains its own code and contains its own `models.py` and `views.py`

The Django Admin page is also an app

Apps can be made reusable, and can be shared with others as plug-ins or extensions
