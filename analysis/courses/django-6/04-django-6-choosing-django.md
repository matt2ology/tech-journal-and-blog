> [!abstract] Executive Summary & Core Thesis
>
> 1. [Django](https://www.djangoproject.com/) [[n11-django-6-choosing-django-strengths|is a backend framework, serves static pages, with the ability to extend features via packages; given these points, requires a JavaScript frontend if one requires an interactive user interface (UI)]]
> 2. [Django](https://www.djangoproject.com/) is fully featured web application framework with [[n12-django-6-choosing-django-python-alternatives|alternatives]] such as:
>    - [Flask](https://flask.palletsprojects.com/en/stable/): microframework - good for smaller projects
>    - [FastAPI](https://fastapi.tiangolo.com/): for highly performant REST APIs
> 3. [[n13-django-6-choosing-django-non-python-alternatives|Other popular, non-python, backend web application frameworks]] includes [Laravel](https://laravel.com/) and [.Net Core](https://learn.microsoft.com/en-us/aspnet/core/overview?view=aspnetcore-10.0), but both lack the robust admin interface of Django
